# Narrated demo video

Built with the pitch-video skill (Playwright clips, real terminal replays, Edge neural narration).
`demo.json` is the cut (19 scenes, 3:44), `scenes.json` the recorder config, `schedules/` the terminal
replays built by the `make_*.cjs` scripts from the real run logs in `*.log` (testnet runs on Nov 6, 2026
and a sandbox `pnpm demo:dry`). Clips, fonts and the rendered MP4 live outside the repo.
